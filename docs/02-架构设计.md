# 02 · 架构设计

更新日期：2026-09-22。本仓库实现为 Vue 工程，本文文件路径相对于仓库根目录。

## 技术与运行

Vue 3、JavaScript、Vite、Tailwind CSS。没有服务器业务接口、账号或远程数据库。Vite 在本地 127.0.0.1:8080 提供开发页面；`./index.html` 通过 `./src/main.js` 挂载 `./src/App.vue`。

## 模块职责

| 模块 | 职责 |
| --- | --- |
| `./src/App.vue` | 页面协调、表单开关、删除目标、任务操作和视图切换 |
| `./src/components/common/` | 弹窗、选择器、提示和空状态 |
| `./src/components/task/` | 表单、列表项、卡片与徽标 |
| `./src/components/board/` | 看板列和事件传递 |
| `./src/composables/` | 任务状态、主题偏好、筛选、顺序和统计 |
| `./src/models/` | 校验、任务构造、状态流转、排序和存储读写 |
| `./src/constants/、./src/types/` | 枚举、约束与类型说明 |
| `./tests/unit/` | 领域与组件回归测试 |

## 数据流

界面事件 → 统一任务操作 → 更新内存集合 → 尝试持久化 → 派生列表、看板与统计。视图不维护独立任务副本。

TaskForm 显式向 AppModal 传递 open；AppModal 仅在 open 为真时渲染遮罩和对话框。取消只关闭，确认才提交。TaskForm 导入 AppSelect，避免选择器未解析。

TaskCard 拖拽携带任务标识，BoardColumn 接收后通过 BoardView 与 App 调用 useTasks.setStatus，复用状态选择器的领域路径。拖拽不创建任务副本。同栏拖动通过 useTasks.reorder 调用 insertTask，按目标卡片上下半部确定插前或插后；只重编号当前列，保留其他任务相对顺序、其他列和内容更新时间。紫色线指示落点。

## 数据模型与存储

任务包含 id、title、description、status、priority；Vue 既有字段还包括 order、createdAt、updatedAt、completedAt。dueDate 与 tagIds 为预留，不承诺对应界面功能。

列表与看板按 order 派生，状态变化时置于目标列顶部。合法顺序可为零或负数，不能用真假判断是否传入数值。

| 存储键 | 格式 |
| --- | --- |
| task-manager:tasks:v1 | JSON 对象，包含 schemaVersion 和任务集合 data |
| task-manager:prefs:v1 | JSON 对象，包含 schemaVersion 和偏好 data |
| task-manager:backup:v1 | 既有原始文本备份，不是完整备份恢复系统 |

主题首帧读取 data.theme，运行时修改 html 深色类。状态更改立即尝试保存；失败保留内存状态并提示。数据只在当前浏览器来源内保存。

## 边界

存储事件不提供事务或冲突合并；不承诺多标签页同时编辑安全。无云同步、加密、恢复入口。界面采用文本插值，领域层不进行 HTML 执行。性能和跨浏览器能力需实际验证，不由架构推断保证。
