# 风险分析

更新日期：2026-09-24。分析对象为本仓库唯一维护的 Vue 工程，路径说明见 `./README.md`。

| 风险 | 影响 | 当前措施与边界 |
| --- | --- | --- |
| 直接双击入口 HTML | Vue 模块无法加载 | 使用 npm run dev，运行方式见 `./README.md` |
| 弹窗未受开关控制 | 遮罩阻断按钮，取消无效 | 已补 open 属性及条件渲染，增加组件测试并做真实浏览器验证 |
| 只跑领域测试与构建 | 实际页面故障漏检 | 页面改动要求浏览器验证；不再用单测数量代替交互结果 |
| npm 官方源连接失败 | 无法安装 | 可临时使用备用镜像，锁文件部分下载地址也使用镜像；网络需要可访问这些地址，不关闭证书校验 |
| 端口被占或监听 EACCES | 开发服务无法启动 | 默认使用 IPv4 与 8080；其他设备若不可用，可用 npm run dev -- --port 8081 指定可用端口 |
| localStorage 不可用、清理或损坏 | 刷新丢失或无法读取 | 有接口故障测试和提示设计；真实浏览器故障注入及恢复功能未完成 |
| 多标签页编辑 | 较晚写入覆盖数据 | 单标签页作为演示边界，无并发冲突协调 |
| 触屏拖拽与兼容性 | 部分设备无法拖动 | 状态选择器提供等效操作；真机和其他浏览器待验证 |
| 手机宽度列表排版 | 390px 宽度下任务文字被挤成竖排，阅读困难 | 已保留 `./docs/demo/Vue版/09-手机宽度列表.png` 作为复现证据；列表响应式布局待修复 |
| 确认误删 | 无法恢复 | 回显标题并二次确认；无回收站，不用于重要数据的唯一保存 |
| 本地明文或特殊输入 | 隐私暴露、潜在渲染漏洞 | Vue 文本插值；不承诺加密，特殊输入的浏览器专项仍待测 |
| 大量任务与可访问性 | 性能或操作受限 | 当前面向少量任务；性能上限、屏幕阅读器和缩放专项未测 |

## 演示与后续

演示前在实际浏览器打开 http://127.0.0.1:8080/，检查创建、拖拽、刷新和删除。使用非敏感示例数据，不同时编辑多个标签页。

当前界面修复、组件测试和浏览器结果见 `./docs/测试设计.md`。后续优先修复手机列表排版，并补存储故障注入、编辑取消、特殊输入和键盘焦点验证；出现真实需求再考虑备份与迁移，不继续扩展流程门槛。
