# 01 · 需求规格说明书

更新日期：2026-09-22。依据课堂任务要求与当前 Vue 版功能范围。

## 定位与范围

个人本地任务管理工具，使用 Vue 3、Vite、Tailwind CSS 和 localStorage。无需登录或后端，不提供协作、云同步、附件、提醒推送及复杂任务依赖。

课堂必需功能是增删改查、三种状态、三档优先级、三列看板与跨列拖拽、深色模式和刷新保留。列表、搜索、统计与既有上下移动作为便利功能保留。标签、截止日期、迁移器、备份导入导出不自动排期。

## 功能与验收

| 编号 | 功能 | 验收要求 |
| --- | --- | --- |
| R01 | 创建与查看 | 标题去首尾空白后必填且不超过 60，描述选填且不超过 500；默认待办、中优先级；新任务立即显示 |
| R02 | 编辑 | 可修改标题、描述、状态与优先级；保存生效，取消保留原值，标识不变 |
| R03 | 删除 | 仅点击删除时显示确认框，回显任务标题；取消不删，确认后移除，刷新不恢复 |
| R04 | 状态与优先级 | 待办、进行中、完成任意切换；高、中、低以文字和红、黄或琥珀、绿表达 |
| R05 | 看板拖拽 | 桌面三列，鼠标跨列拖拽立即改状态；不产生副本；选择器提供等效操作，不要求触屏拖拽 |
| R06 | 主题 | 浅色与深色切换，刷新后恢复主动选择；不要求三态主题 |
| R07 | 本地存储 | 任务修改后保存；读取失败可继续打开，写入失败明确提示刷新风险；不承诺损坏恢复 |
| R08 | 列表切换 | 与看板使用同一任务数据 |
| R09 | 搜索筛选 | 标题、描述搜索及既有状态、优先级筛选；清空后恢复 |
| R10 | 数量统计 | 与任务状态一致，不维护独立数据副本 |

长度按 JavaScript 字符串长度计算。输入按文本展示，不执行 HTML。表单关闭放弃未保存内容，无草稿恢复；删除无撤销。首次打开不得有弹窗遮罩阻断操作。

## 使用边界

运行入口为 `http://127.0.0.1:8080/`，由 `npm run dev` 提供。通过 `./README.md` 安装和启动，所有文件路径均以仓库根目录为基准。

同浏览器、同访问来源刷新保存有效；清理数据、换浏览器或访问地址可能导致原记录不可见。适用于少量个人任务，不设置未经验证的千条性能指标。

手机端可用选择器改状态，看板允许局部横向滚动；不宣称触控拖拽和完整可访问性合规。构建、领域测试、组件测试、浏览器测试分别记录。

## 验收顺序

首次无弹窗 → 创建 → 编辑 → 看板拖拽 → 主题切换 → 刷新 → 取消删除 → 确认删除 → 再次刷新。实际结果及未测边界见 `./docs/04-测试设计.md`。

补充：R05 支持同栏卡片拖拽排序，目标上半部插前、下半部插后，显示插入线；刷新后保存顺序。跨栏仍为状态变更并置顶。
