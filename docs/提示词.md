#### 非功能需求（分层）

- **NFR-01** 性能（MVP）：1000 条任务下列表首屏渲染 < 200 ms
- **NFR-02** 兼容性（MVP）：Chrome / Edge / Firefox / Safari 最近两个大版本
- **NFR-03** 响应式（MVP 基础）：≥1024 px 三列看板，<768 px 单列堆叠
- **NFR-04** 可靠性（MVP）：localStorage 异常时降级提示
- **NFR-05** 可维护性（MVP）：核心逻辑单测覆盖率 100%，整体 ≥80%
- **NFR-06** 可访问性（MVP 基础）：语义化标签、可见焦点、对比度 WCAG AA
- **NFR-07** 隐私（MVP）：纯本地运行，零网络请求
- **NFR-08** 可演进性（MVP）：存储 key 带 schema 版本号

#### 技术基线默认值

- **技术栈**：Vue 3.5+（`<script setup>`）+ Vite 7 + Tailwind CSS v4（`@tailwindcss/vite`，CSS-first，`@custom-variant dark`）+ localStorage
- **运行时**：Node ≥ 20.19，包管理器 npm
- **测试**：vitest + @vue/test-utils + jsdom
- **质量**：ESLint + Prettier + husky/lint-staged 提交门禁

#### 变更内容

| 变更项 | 原方案 | 新方案 |
| --- | --- | --- |
| **新增 FR-13** | 无 | 任务顺序调整（P0，MVP）——列表视图与看板每列均提供上移/下移按钮 |
| **FR-02 修订** | 按更新时间倒序排序 | 按 `order` 升序排序；`updatedAt` 降级为展示字段 |
| **EX-02 修订** | 列内手动拖拽排序（P2） | 拖拽排序（列内插入定位 + 跨列位置，P2），复用同一套 order 逻辑 |
| **DC 修订** | `order` 为预留字段 | `order` 升级为 MVP 启用字段 |

#### 派生规则待确认

三条规则要求用户确认：

**R1 · 顺序唯一真相**
全局单一整数 `order`，列表与看板共用一份数据；看板每列按 `order` 升序过滤显示。上移/下移 = 与当前可见序列中的相邻项交换。

**R2 · 落位规则**
新建任务、以及状态变更后的任务，均置于目标列顶部（最新操作可见性最好），之后可用上移/下移微调。

**R3 · 边界与可访问性**
可见序列首位禁用"上移"、末位禁用"下移"（禁用态 + `aria-label`/`title` 说明原因）；按钮键盘 Tab 可达；EX-05 筛选启用后，"相邻"以当前可见序列为准而非全量数据。
