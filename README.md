# Task Manager

使用 Vue 3、Vite 和 Tailwind CSS 构建的个人任务管理应用。数据保存在当前浏览器，无需账号或后端服务。

## 功能

- 任务创建、编辑、删除，支持描述和高、中、低优先级。
- 待办、进行中、完成三种状态，列表与看板视图。
- 跨栏拖动改变状态，同栏拖动调整顺序；紫色线提示插入位置。
- 标题与描述搜索，状态和优先级筛选。
- 浅色与深色切换，任务和偏好刷新后保留。

## 环境要求

需要 Node.js 和 npm。当前 Vite 要求 Node.js 20.19 及以上的 20.x，或 22.12 及以上；已验证环境为 Node.js 24.19.0。使用现代桌面浏览器，触屏设备可通过状态选择器操作。

所有命令均在仓库根目录执行，即包含 `./package.json` 的目录。本文及 docs 内的文件路径，除明确说明外，均相对于仓库根目录。

## 获取与启动

在 GitHub 仓库页面通过 Code 复制仓库地址进行克隆，或下载 ZIP 并解压，然后进入项目目录打开终端。

依次执行以下命令，只复制命令，不要复制代码块前后的三个反引号。

```sh
npm ci
npm run dev
```

默认打开 `http://127.0.0.1:8080/`，以终端实际输出为准。保持终端运行；停止服务按 Ctrl+C。不要双击 `./index.html`，它需要 Vite 加载 Vue 模块。

如果 8080 被占用或出现监听权限错误，可换用其他可用端口：

```sh
npm run dev -- --port 8081
```

改端口后使用终端显示的新地址。浏览器数据按来源隔离，更换端口可能看不到之前的数据。

安装依赖时若默认源连接失败，可以临时指定镜像：

```sh
npm ci --registry=https://registry.npmmirror.com
```

`./package-lock.json` 中部分包的下载地址使用该镜像；复现安装需要相应下载地址可访问。无需修改全局 npm 配置或关闭证书校验。

## 使用方式

点击“新建任务”填写标题，描述选填。看板中拖住卡片标题或空白区域：拖到其他栏更改状态；拖到同栏目标卡片上半部插在它之前，下半部插在它之后。按钮和状态选择器用于点击操作。

删除需要确认，确认后不可撤销。数据只保存在当前浏览器，不会随 Git 提交上传，也不提供跨设备同步；清理站点数据会丢失任务。

## 测试和构建

```sh
npm run test:unit
npm run lint
npm run build
```

生产产物位于 `./dist/`。本地检查构建结果：

```sh
npm run preview -- --host 127.0.0.1 --port 8081
```

打开终端输出的网址。preview 仅用于本地预览，不是生产托管服务。上传源码到 GitHub 不会自动发布可访问的网站；如需 GitHub Pages，需要另行配置构建、部署及仓库子路径。

## Git 提交范围

提交源码、测试、文档、配置和依赖锁文件。`./node_modules/`、`./dist/`、缓存及本地工具资料由 `./.gitignore` 排除。其他人取得仓库后通过 npm ci 重建依赖，无需开发者的本机目录。
